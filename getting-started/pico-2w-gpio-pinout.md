# Raspberry Pi Pico 2 W GPIO Pinout

![Raspberry Pi Pico 2 W GPIO Pinout](/assets/images/slides/6_GPIO_Pinout.jpg)
{: .mt-6 }

You can check out the full Raspberry Pi Pico 2 W Pinout at the page linked below.\
[Full Raspberry Pi Pico 2 W Pinout →](https://pico2w.pinout.xyz/)

{: .note }
Notice that **Ground** (GND) pins are repeated after every 4 pins, and start after 2 pins in each end. Remembering this will make verifying the pin positions easier. The ground pins also have a square copper shape around the pin on the Pico board to make them easier to recognize.
