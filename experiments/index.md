# Experiments

Write your first script "blink.py" by following the instructions below. Once you get it to work on your Pico, try connecting the humidity and temperature sensor in the next experiment. After that, try random experiments from the list below. Some experiments need additional sensors from the common additional sensors kit to be shared by all teams. The complete code for all the experiments is also available on [GitHub](https://github.com/goatoush/inventor-pi).
